# 🌦️ Weather App

A simple Weather App built using **HTML, CSS, and JavaScript** that shows real-time weather data using an API.

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡️ Shows temperature in Celsius  
- ☁️ Displays weather condition  
- ⚡ Fast and simple UI  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  
- OpenWeather API
